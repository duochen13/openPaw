### 1.2 The 5 graded student papers

| # | Item | Done |
|---|------|------|
| P1 | 5 student papers, already graded by the teacher (graded originals preferred over re-grades) | ☐ |
| P2 | Score spread across the 5: at least one high, one middle, one low — note each paper's total score | ☐ |
| P3 | For the 2 students the teacher knows best: weakest-skill judgment filled in (§2 template) | ☐ |
| P4 | Every paper fully legible in the photo/scan (see §4 photo-quality questions) | ☐ |

### 1.3 Anonymization (do this BEFORE anything enters the repo)

Students are minors. **Anonymization is mandatory** — no names, no handwriting quirks that identify a student beyond an ID, no class roster data.

1. ☐ Assign IDs **S01–S05** (print or write the ID on a sticky note covering any name on the paper *before* photographing).
2. ☐ Strip from every photo/scan: student name, class, student number, any teacher marginalia naming the student.
3. ☐ Check the background of each photo (desks, notebooks, other papers in frame) for identifying info.
4. ☐ Keep a private ID↔name map (which real student is S01, …) in a notebook/file that **stays OFF the repo** — only the teacher holds it. The repo stores student-ID-only materials.
5. ☐ Daniel spot-checks every file for leaked identifiers before committing.
