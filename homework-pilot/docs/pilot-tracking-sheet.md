## 2. Question-modification log · 生成题修改/拒绝记录

One row per generated question that was modified or rejected. Question ID = the generated question's ID in the question bank.

| Date · 日期 | Question ID · 题目编号 | Target skill · 目标技能 | Modified or rejected · 修改/拒绝 | Reason category · 原因类别 | Description · 说明 |
|---|---|---|---|---|---|
| YYYY-MM-DD |  |  | modified / rejected |  |  |

Reason categories (pick one; see protocol §3 M4):

- 条件不充分 condition insufficient
- 答案不唯一 answer non-unique
- 评分不接受合理替代解法 scoring rejects reasonable alternatives
- 公式单位错误 formula/unit errors
- 图文不一致 figure–text mismatch
- 难度不匹配 wrong difficulty
- 超出已教范围 untaught content
- 其他 other
