# 个性化科学作业：教师试点设计

状态：用户已认可产品方向；本文整理已确认需求及待验证假设。
日期：2026-09-27。

## 目标与试点范围

帮助教师提高学习有困难的学生的成绩，并减少已经掌握内容的无效重复练习。
第一位试点教师为用户的母亲，她教两个班，约80名学生。
初始内容范围为浙教版科学九年级上册第三章《能量的转化与守恒》，以教师实际使用的教材和教学进度为准。
全年持续更新学习记录是产品需求；首轮试点只能验证短期流程和学习变化，不能证明全年效果。

## 已有证据与未知项

目前教师向所有学生布置相同作业，希望提高学习困难学生的成绩。
用户已提供本章空白题目截图，包含文字、公式、图示、选择题和多空填空题。
尚未获得学生作答、教师批改、真实使用反馈或学习效果数据。
教师本人是否愿意持续采用该流程、可接受的审核时间和学校允许的作业差异程度，仍需验证。
用户希望个性化作业作为正式作业，而非统一作业之外的一律加量。

## 已确认的产品流程

1. 教师提供原题、参考答案，并上传批改后的学生纸质作业照片或扫描PDF。
2. 系统关联学生、作业、页码和小题，识别作答与批改痕迹。
3. 教师核对无法可靠识别的内容，并确认或修改系统提出的薄弱点。
4. 经确认的作答证据更新学生的长期学习记录。
5. 教师设置当前教学范围和作业长度，系统按学生情况混合当前学习、薄弱点练习和旧知识复习。
6. 教师审阅、替换或调整题目后，下载学生作业PDF及独立的教师答案和评分说明。
7. 学生在纸上完成作业，后续上传形成新的学习证据。

学生无需在线答题或拥有产品账号。
支持单个学生下载，也支持全班批量导出。
建议打印学生编号与作业编号，方便下一次上传匹配；匹配不确定时必须由教师确认。

## 学习记录

每位学生按具体技能维护当前判断，同时保留有日期的历史证据。
记录包括题目及小题、知识点、学生回答、批改结果、原图位置、是否使用提示或订正、教师修正及后续验证。
当前状态可表达为证据不足、需要练习、正在改善、已有较充分掌握证据和待复习。
这些是可修正的教学判断，不是学生的固定标签。
识别文字是否可靠与判断学生是否掌握是两种不同的不确定性，应分开呈现。
一次答错只能支持待验证的薄弱点假设，一次答对也不能证明长期掌握。
近期独立完成的不同情境题应提供新的证据，订正或重复同一道题不能等同于独立掌握。
长期没有新证据时，可以安排复习检查，但不能直接声称学生已经遗忘。
保存历史并更新当前判断；教师应能查看判断依据并纠正错误记录。
不在初版显示缺乏校准依据的精确掌握百分比。

## 本章的技能粒度示例

| 技能 | 用户提供的题目样本 |
|---|---|
| 根据力与沿力方向的位移判断指定力做功 | 第2题 |
| 判断推下木板所需的位移并结合摩擦力计算功 | 第3题 |
| 估算物理量并计算平均功率 | 第4、6题 |
| 比较功与功率，排除无关条件 | 第7题 |
| 计算重力做功 | 第8题 |
| 判断做功阶段、最高点动能、重复跳跃功率 | 第11题各小题分别记录 |
| 联系重力做功、弹性势能及受力与速度变化 | 第12题各填空分别记录 |

这些是基于样本的初步标签，需教师确认，并非完整教材知识体系。
综合题可能涉及多个技能；只凭最终错误答案不能确定究竟哪个环节有问题。

## 个性化作业规则

教师决定当前教学主题、允许复习的范围及题量或预计完成时间。
系统按每位学生的证据动态混合当前学习、薄弱点练习和旧知识复习，不预设全班固定比例。
薄弱点改善后减少同类重复练习，通过不同情境或间隔后的问题检查是否仍然掌握。
发现新的或重复的困难时，增加适当的诊断或基础练习；必要时提示教师需要讲解，而不是无限增加题量。
未教授的内容和缺少证据的内容不能直接视为薄弱点。
教师可保留少量共同题，方便统一讲评和可比的学习检查。

## 出题、审核与打印

初始题目由AI生成，互联网材料仅作为允许使用时的补充来源，不默认无限制抓取或复制。
每道题应附目标技能、推荐原因、预期难度、答案、解题过程及评分说明。
生成题在发布前需检查条件是否充分、答案是否唯一或评分是否接受合理替代解法、公式单位以及图文是否一致。
题库审核以共享题目为单位，减少教师逐份重复审查80套作业的负担。
含图题是已确认需求；无法可靠生成或识别的图示应标记待审核，不应悄悄忽略。
学生PDF应有清晰图示、足够作答空间和稳定分页，答案另行导出。
教师批准后才能作为正式作业发布。

## 方案比较与选择

| 方案 | 优点 | 局限 | 决定 |
|---|---|---|---|
| 统一作业加补弱练习 | 对现有课堂安排改动较少 | 容易增加总负担，未充分减少重复 | 不作为核心方向 |
| 一次错题生成一次练习 | 流程简单，能快速展示 | 无法反映长期改善或复习需要 | 可作技术演示，不能代表产品 |
| 长期记录驱动的混合作业 | 随学习进展变化，同时支持新课与复习 | 依赖可靠证据和可接受的教师审核成本 | 用户认可的产品方向 |

## 试点验证建议

先选择本章一个小范围和8至10位学生，验证上传、核对、出题和打印的完整流程，再扩大到两个班。
人数和具体安排是建议，尚未与教师确认。
记录识别错误、学生或页码匹配错误、教师修正的技能判断、生成题被修改或拒绝的原因，以及每次审核所用时间。
使用难度相近但不同题目的前后检查，并安排后续复习检查，避免把记住原答案误认为掌握。
记录学生完成时间和作业量，防止成绩变化只是额外加量造成。
小样本的前后变化不能单独证明产品带来因果效果，扩展试点时需设计更可比的评估。
成功标准和可接受的教师审核时间由教师在试点前确定，目前不编造目标数值。

## 待确认事项

- 教师是否愿意试用，以及愿意从哪个知识点开始。
- 教材版本、原卷完整内容、参考答案和学生答案写在原卷还是另纸。
- 上传由谁完成、纸张如何对应学生，以及照片通常能达到什么质量。
- 教师期望的题量、打印方式和实际可接受的审核工作量。
- 学生材料的访问权限、外部处理服务选择、保存期限以及纠错和删除方式。
- 如何处理无法辨认的作答、缺页、缺少标准答案及学生未独立完成的情况。
